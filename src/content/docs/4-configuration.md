## Configuration

| File | What it sets |
| --- | --- |
| `quickshell/config.js` | Colors, fonts, sizes |
| `quickshell/topbarlayout.json` | Bar widget order |
| `hypr/binds.lua` | Keybinds |
| `hypr/looknfeel.lua` | Gaps, borders, animations |
| `hypr/programs.lua` | Terminal, browser, file manager |
| `hypr/autostart.lua` | What starts with the session |

Saving a QML file live-reloads the shell. No restart needed.
