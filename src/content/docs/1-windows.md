## Windows

| Keys | Action |
| --- | --- |
| `Super` `Return` | Terminal |
| `Super` `W` | Close window |
| `Super` `Space` | Toggle floating |
| `Super` `J` | Toggle split |
| `Super` `1-9` | Go to workspace |
| `Super` `Shift` `1-9` | Move window to workspace |
| `Super` `S` | Scratchpad |
| `F11` | Fullscreen |
