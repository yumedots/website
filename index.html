Get it

Monochrome Hyprland, built by hand. By yumedots

A bar, launcher and widgets written in QML. A compositor configured in Lua. Black, flat, square and fast.

Get the dotfiles View on GitHub

Everything on screen is mine.

No borrowed bar, no theme pack. Every widget, popup and menu is a QML file in quickshell/, and every bind, rule and animation is Lua in hypr/.

One white border, no rounding, no blur, no shadows. Colors only show up where they mean something: CPU is violet, memory is green, weather is blue.

Fork it, read it, take what you like.

Install

Clone, copy, log into Hyprland. Everything autostarts.

Clone and copy

Back up your ~/.config first.

$ git clone --recursive https://github.com/yumedots/dotfiles ~/dotfiles
$ cp -r ~/dotfiles/* ~/.config/

You'll need

These are expected on your system before the first login.
